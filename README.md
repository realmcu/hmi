## Build

### Option 1: Use the VS Code extension (recommended)

Install the Ameba VS Code extension to configure the SDK environment, build the project, and flash the firmware with one click:

1. Install the extension according to the [VS Code User Guide](https://aiot.realmcu.com/cn/latest/rst_tools/vscode/index.html)
2. Open the workspace directory `~/workspace/ameba-honeygui` in VS Code
3. Use the graphical interface provided by the extension to configure and build

### Option 2: Manually configure the build environment

Refer to the [FreeRTOS SDK User Guide](https://aiot.realmcu.com/cn/latest/rst_rtos/rst_sdk/index.html) and perform the following steps:

```bash
cd ~/workspace/ameba-honeygui/ameba-rtos

# 1. Configure the SDK environment
#    Linux:   source env.sh
#    Windows: env.bat

# 2. Select the target chip
#    HoneyGUI currently supports the AmebaGreen2 series (RTL8721F)
python ameba.py soc rtl8721f

# 3. Configure the project
#    Enable: Graphics Libraries → Use HoneyGUI
#    Enter HoneyGUI Configuration for detailed settings
python ameba.py menuconfig

# 4. Build the project
python ameba.py build

# 5. Flash the firmware (replace <PORT> and <BAUDRATE> with actual values)
python ameba.py flash -p <PORT> -b <BAUDRATE> -i <BIN_FILE> <START_ADDR> <END_ADDR>

# 6. Serial monitor (optional)
python ameba.py monitor -p <PORT> -b 1500000
```

## Configuration

HoneyGUI-related Kconfig options:

- `GRAPHIC_UI` — enable the graphical UI module (in `ameba-rtos/component/ui/Kconfig`)
- `USE_HONEYGUI` — select HoneyGUI as the graphics library
- `HONEYGUI_ENABLE` — enable HoneyGUI (automatically selected by `USE_HONEYGUI`)
- `REALTEK_BUILD_HONEYGUI_APP` — build the HoneyGUI application
- `HONEYGUI_APP_DASHBOARD` — build the Dashboard sub-application
